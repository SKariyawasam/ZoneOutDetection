# Wearable App (Module B)

This directory is intended for the Flutter / WearOS application.
Currently, `flutter` is not installed or not available in your system PATH.

## Next Steps
1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install/windows).
2. Install Android Studio and set up a WearOS emulator or connect your Galaxy Watch 7 via ADB.
3. Once installed, run `flutter create .` inside this folder to initialize the app.
